🔌 OPTIONAL INTEGRATIONS:

   1. OPENAI (Alternative AI - Most Capable)
   ─────────────────────────────────────────
   URL:      https://platform.openai.com
   Key:      Starts with 'sk-'
   Env Var:  OPENAI_API_KEY
   Rate:     60 requests/min

   2. ANTHROPIC (Alternative AI - Best for Safety)
   ────────────────────────────────────────────────
   URL:      https://console.anthropic.com
   Key:      Starts with 'sk-ant-'
   Env Var:  ANTHROPIC_API_KEY
   Rate:     50 requests/min

   3. EMAIL (Gmail)
   ────────────────
   URL:      https://myaccount.google.com/apppasswords
   Env Vars: JARVIS_EMAIL_ADDRESS
             JARVIS_EMAIL_APP_PASSWORD
   Note:     Requires 2FA enabled on Google

   4. TWILIO (WhatsApp & Phone)
   ────────────────────────────
   URL:      https://console.twilio.com
   Env Vars: TWILIO_ACCOUNT_SID (starts with 'AC')
             TWILIO_AUTH_TOKEN
             TWILIO_FROM_PHONE
             TWILIO_FROM_WHATSAPP
   Note:     Free trial includes $15 credit

   5. SPOTIFY (Music Control)
   ──────────────────────────
   URL:      https://developer.spotify.com/dashboard
   Env Vars: SPOTIFY_CLIENT_ID
             SPOTIFY_CLIENT_SECRET
   Note:     Set Redirect URI to http://localhost:8888/callback

   6. HOME ASSISTANT (Smart Home)
   ──────────────────────────────
   URL:      Your HA instance
   Env Vars: HOME_ASSISTANT_URL
             HOME_ASSISTANT_TOKEN
   Note:     Get token from Profile → Long-Lived Access Tokens

⚠️ COMMON ERRORS & SOLUTIONS:

   "Invalid API Key"
   → Double-check the key in .env
   → Make sure no extra spaces
   → Regenerate if needed

   "Rate Limited"
   → Wait a minute and try again
   → Reduce request frequency
   → Upgrade API plan

   "Network Error"
   → Check internet connection
   → Verify API endpoint accessible
   → Check firewall settings

   "Module not found: cryptography"
   → pip install cryptography
