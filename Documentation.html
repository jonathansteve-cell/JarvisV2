Overview

Jarvis V2 is a comprehensive desktop AI assistant that combines voice control, automated research, gaming assistance, and productivity tools into a single application.

🎤 Voice Control

Natural language voice commands with multiple voice profiles.

🔬 Research Mode

Automated topic research with organized folders and reports.

🎮 Roblox Grind

Automated Roblox gaming with progress tracking.

💼 Serious Mode

Productivity workspaces for learning and work.

Features

Core Features

  • 19+ built-in modules
  • Voice recognition and text-to-speech
  • AI-powered conversations (Groq, OpenAI, Anthropic)
  • System control (volume, apps, screenshots)
  • Web search and automation
  • Email, WhatsApp, and phone integration
  • Spotify music control
  • Smart home integration

New Modes

  • NEW Research Mode - Automated topic research
  • NEW Roblox Grind Mode - Automated gaming
  • NEW Serious Mode - Productivity workspaces

Installation

Windows

# Download and run the installer
JarvisV2-Setup.exe

# Or use the portable version
JarvisV2-Portable-2.0.0.zip

From Source

# Clone the repository
git clone https://github.com/jonathansteve-cell/JarvisV2.git
cd JarvisV2

# Run the start script
start.bat

Quick Start

First Launch

  1. Run start.bat or JarvisV2.exe
  2. Complete the setup wizard
  3. Create your account
  4. Configure API keys (optional)
  5. Start using Jarvis!

Hey Jarvis, what time is it? Hey Jarvis, system status Hey Jarvis, tell me a joke

Troubleshooting

Common Issues

Application won't start

Make sure Python 3.10+ is installed and added to PATH.

Voice not working

Check microphone permissions and install PyAudio:

pip install pyaudio

API errors

Verify your API keys in the Settings panel.
