# Jarvis V2 - How to Launch

## 🚀 Quick Start

### **Windows**
```bash
# Double-click start.bat
start.bat
```

### **Linux/macOS**
```bash
# Make executable and run
chmod +x run_local.sh
./run_local.sh
```

### **Direct Launch**
```bash
python launch_voice_ui.py
```

## 🎤 How to Use

### **1. Click "🎤 START LISTENING"**
- The button will change to "⏹ STOP LISTENING"
- Voice visualizer will start moving
- Jarvis is now listening

### **2. Speak Your Command**
```
"Hey Jarvis, what time is it?"
"Hey Jarvis, system status"
"Hey Jarvis, tell me a joke"
```

### **3. Jarvis Responds**
- Voice response through speakers
- Visual feedback on screen

## 🔧 Troubleshooting

### **"Python not found"**
Install Python 3.10+ from https://python.org

### **"tkinter missing"**
```bash
# Linux
sudo apt install python3-tk

# macOS
brew install python-tk@3.11
```

### **"Voice not working"**
```bash
pip install pyaudio
```
