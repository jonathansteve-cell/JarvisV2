# Jarvis V2 - Modes Guide

## 🎯 Overview

Jarvis V2 now includes three powerful new modes:

1. **Research Mode** - Automated topic research with organized folders
2. **Roblox Grind Mode** - Automated Roblox grinding for Robux
3. **Serious Mode** - Open workspaces for learning and productivity

---

## 🔬 Research Mode

### **What It Does**
- Researches any topic automatically
- Gathers information from Wikipedia and web
- Creates organized folder structure
- Generates comprehensive reports
- Tracks sources and notes


#### **Search for More Info**
```

```

#### **Open Websites**
```

Hey Jarvis, open Google Scholar
```

#### **Generate Report**
```

Hey Jarvis, finish research
```

#### **View Status**
```

```

#### **List Past Research**
```

Hey Jarvis, show research history
```

### **Folder Structure**
```
research/
└── artificial_intelligence_20260830_143022/
    ├── research_log.md          # Main log
    ├── RESEARCH_REPORT.md       # Final report
    ├── quick_facts.md           # Key facts
    ├── sources/
    │   ├── wikipedia.md         # Wikipedia info
    │   ├── web_search.md        # Search results
    │   └── sources_list.json    # All sources
    ├── notes/
    │   └── research_notes.md    # Your notes
    └── images/                  # Saved images
```

### **Features**
- ✅ Automatic Wikipedia integration
- ✅ Web search via DuckDuckGo
- ✅ Source citation and tracking
- ✅ Note-taking system
- ✅ Report generation
- ✅ Organized folder structure

## 💡 Tips

### **Research Mode**
- Start with broad topics, then narrow down
- Add notes as you learn new things
- Use web search for recent information
- Generate report when done

### **Roblox Grind Mode**
- Set realistic goals for each session
- Take breaks every 30-60 minutes
- Track your progress over time
- Try different games to find favorites

### **Serious Mode**
- Use focus mode to avoid distractions
- Take regular breaks (Pomodoro technique)
- Keep your workspace organized
- Review your session history

## 🔧 Customization

### **Add Custom Games (Roblox)**
Edit `modules/roblox_grind_controller.py`:
```python
GRIND_GAMES["my_game"] = {
    "name": "My Game",
    "url": "https://www.roblox.com/games/...",
    "description": "My favorite game",
    "avg_robux_per_hour": 50,
    "difficulty": "Easy"
}
```

### **Add Custom Workspaces**
Edit `modules/serious_mode_controller.py`:
```python
WORKSPACES["my_workspace"] = {
    "name": "My Workspace",
    "description": "Custom workspace",
    "apps": [
        {"name": "App1", "command": "app1", "platform": "all"}
    ],
    "websites": ["https://example.com"],
    "focus_mode": True
}
```
