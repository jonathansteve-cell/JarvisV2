### Notes

- **Dangerous actions** (restart, shutdown, delete) require the `allow_dangerous_actions` setting in `config.yaml`.
- **Integrations** (Email, WhatsApp, Spotify, Zoom, Smart Home) need API keys / credentials in `.env`.
- Voice commands require a working microphone and `SpeechRecognition` / `PyAudio`.
