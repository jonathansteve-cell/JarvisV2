# Security Notes

- Do not commit `.env` files.
- Do not publish Groq, Twilio, Spotify, email, Twitter, LinkedIn, Home Assistant, or Google credentials.
- Use app passwords and scoped tokens whenever possible.
- Dangerous power commands are confirmation-protected by default.
- Jarvis cannot and should not bypass account security, 2FA, permissions, or legal boundaries.
- Review commands before enabling destructive actions such as shutdown/restart/delete.
