## 🔧 Customization

### Change Icon Design
1. Replace `packaging/app.png` with your custom icon (1024x1024 recommended)
2. Run: `python packaging/make_icon.py`
3. Rebuild the installer

### Generate Installer Images
```bash
python packaging/create_installer_images.py
```

This creates:
- `app.bmp` (164x314) - Installer wizard sidebar
- `app_small.bmp` (55x55) - Small wizard image

### Modify Desktop Shortcut
Edit `packaging/installer.iss`:

```ini
[Icons]
; Desktop - PRIMARY SHORTCUT
Name: "{autodesktop}\{#MyAppName}"; \
    Filename: "{app}\{#MyAppExeName}"; \
    Comment: "Your custom tooltip here"; \
    IconFilename: "{app}\{#MyAppExeName}"; \
    IconIndex: 0; \
    WorkingDir: "{app}"; \
    Tasks: desktopicon
```

## 🛠️ Build Process

### Step 1: Generate Icons
```bash
python packaging/make_icon.py
python packaging/create_installer_images.py
```

### Step 2: Build Installer
```bash
# Windows
packaging\BuildInstaller.bat

# Or manually
pyinstaller --noconfirm --clean packaging\jarvis.spec
"C:\Program Files\Inno Setup 6\ISCC.exe" packaging\installer.iss
```

### Step 3: Test Installer
1. Run `dist\installer\JarvisV2-Setup.exe`
2. Verify desktop icon appears
3. Verify icon has correct image
4. Verify tooltip shows on hover
5. Test uninstall removes icon

## 🔍 Troubleshooting

### Desktop Icon Not Appearing
1. Check if "Create desktop shortcut" was selected during install
2. Verify `{autodesktop}` path is correct
3. Check Windows icon cache (restart Explorer)

### Icon Looks Blurry
1. Ensure source image is high resolution (1024x1024)
2. Regenerate with: `python packaging/make_icon.py`
3. Rebuild installer

### Icon Not Updating
1. Clear Windows icon cache:
   ```batch
   ie4uinit.exe -show
   ```
2. Or restart Windows Explorer

### Wrong Icon Showing
1. Verify `app.ico` exists in `packaging/` folder
2. Check `SetupIconFile=app.ico` in installer.iss
3. Regenerate icons

## 🎨 Design Tips

### For Best Results
1. **Use a square source image** (1024x1024 or 512x512)
2. **Simple designs work best** at small sizes
3. **High contrast** ensures visibility on all backgrounds
4. **Test at 16x16** to ensure clarity at small sizes

### Recommended Style
- **Orange/amber color scheme** (matches Jarvis HUD)
- **Simple geometric shapes** (circle, hexagon)
- **Minimal text** (doesn't scale well)
- **Clear silhouette** (recognizable at small sizes)
